# LINE の実機での確認手順(テスト環境・約10分)

デモ用の LINE 公式アカウントとテスト環境で、LINE アプリの中でしか試せないことを確かめます。iPhone と Android の両方で行います(19.3)。2台のスマホ(または2つの LINE アカウント)があると、家族の招待まで試せます。

## 用意するもの

- テスト環境に配信済みであること(`docs/deploy.md`)。LIFF のエンドポイント URL が `https://<配信先>/liff/` になっていること
- 受付の固定QRコード: `https://liff.line.me/<LIFF ID>/checkin?k=<合言葉>` を QR にしたもの(合言葉は管理画面の設定、または `settings` の `checkin_passphrase`)
- 管理画面のアカウント(`docs/deploy.md` の手順で作る)
- デモ用の LINE 公式アカウントのリッチメニューに、`https://liff.line.me/<LIFF ID>/` を置いておく

## 手順

| # | すること | 期待する結果 | iPhone | Android |
| --- | --- | --- | --- | --- |
| 1 | リッチメニューから会員証を開く(はじめての LINE アカウント) | LINE の中で「はじめての方へ」が開く。LINE のログイン画面が出た場合は許可すると続きが開く | ☐ | ☐ |
| 2 | 同意して次へ → 「写真を撮る・選ぶ」でカメラで撮る | カメラが開き、撮った写真が丸く表示される。送信後、会員証に写真が出る | ☐ | ☐ |
| 3 | もう1頭追加し、犬種「その他」を選んで自由入力する | 入力欄が出て、登録後の呼び名が「○○・△△のおうち」になる | ☐ | ☐ |
| 4 | アンケートで郵便番号を入れずに登録する | 登録できて、会員IDが DR- 形式で出る | ☐ | ☐ |
| 5 | LINE のカメラ(ホームの QR 読み取り)で受付のQRを読む | チェックイン画面が開き、犬が全員選ばれている | ☐ | ☐ |
| 6 | チェックインする | 完了画面で時計が秒まで動き、背景のバーが流れている。スクリーンショットを撮ると止まって見える | ☐ | ☐ |
| 7 | 管理画面(タブレットの Safari/Chrome)で今日の来場を見る | 30秒以内に、写真と名前が一覧に出る | ☐ | ☐ |
| 8 | 同じ LINE でもう一度 QR を読む | 「今日はチェックイン済みです」と出て、犬の追加だけができる | ☐ | ☐ |
| 9 | 会員証 → 家族を招待 → 「LINEで招待を送る」 | LINE の送り先を選ぶ画面が開き、送ったトークに招待のリンクが届く | ☐ | ☐ |
| 10 | 2台目の LINE でそのリンクを開き、年代・性別と同意を入れて参加する | 「参加しました」と会員IDが出て、会員証が1台目と同じ内容になる | ☐ | ☐ |
| 11 | 2台目で受付のQRを読む | 「今日は○○さんがチェックイン済みです」と出て、ポイントは増えない | ☐ | ☐ |
| 12 | 会員証 → ワンちゃん → 名前を変えて保存する | 1台目・2台目・管理画面の今日の来場に、すぐ新しい名前が出る | ☐ | ☐ |
| 13 | スマホをダークモードにして会員証とチェックイン完了を開く | 文字が読め、崩れがない | ☐ | ☐ |
| 14 | 管理画面(iPad の Safari)でログインし、ブラウザを閉じて開き直す | ログインが保たれている | ☐ | ― |
| 15 | 管理画面でチェックインを取り消す | 1台目の会員証のポイントが戻る | ☐ | ☐ |

## うまくいかないとき

- 1 で真っ白になる・「LINEとの接続がうまくいきませんでした」: LIFF のエンドポイント URL と、ビルド時の `VITE_LIFF_ID` を確かめる。
- 5 で LINE の外のブラウザが開く: 受付のQRの URL が `https://liff.line.me/<LIFF ID>/...` の形になっているか確かめる。
- 6 のあと「ログインの確認ができませんでした」: `wrangler.toml` の `LINE_CHANNEL_ID` が LIFF を置いたチャネルの ID と一致しているか確かめる。
- 9 で送り先の画面が開かない: LINE Developers の LIFF の設定で「シェアターゲットピッカー」をオンにする。

結果は、できなかった番号と、そのときの画面の写真を添えて知らせてください。
