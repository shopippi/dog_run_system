# 本番運用を始める前のチェックリスト

デモの段階(2026-10-31 時点)から、お客さんに使ってもらう段階に移るときに、上から順に済ませる。だれがやるかを「依頼主」「製作者」で書く。終わったら [x] にする。

## 1. 名義とアカウント

- [ ] (依頼主・製作者)Cloudflare・LINE Developers・LINE公式アカウント・GitHub の名義を依頼主にする(20章)。製作者は招待されたメンバーとして入る
- [ ] (依頼主)LINE公式アカウントを、テスト用の「テストアカウント」から、グリーンドームの公式アカウントに切り替える。Messaging API を有効にするときは、会員証(LIFF)と同じプロバイダーを選ぶ(違うと、トークにお知らせが届かない。一度選ぶと変えられない)
- [ ] (製作者)グリーンドームの公式アカウントのチャネルアクセストークン(長期)を発行し、GitHub の Environment「Secret」の `LINE_MESSAGING_TOKEN` を入れ替える。配信の注釈に「つながりました(グリーンドーム…)」と出ることを確かめる(deploy.md)
- [ ] (製作者)LINE ログインのチャネルの「リンクされた LINE 公式アカウント」をグリーンドームにし、LIFF の「友だち追加オプション」を On (Normal) にする

## 2. LINE のチャネルを公開する

- [ ] (製作者)LINE ログインのチャネルを「開発中」から「公開」にする。開発中のままだと、権限設定に入っている人しか会員証を開けない
- [ ] (製作者)LIFF のエンドポイント URL が本番の `/liff/` になっていることを確かめる

## 3. パスワードとアカウント

- [ ] (製作者)GitHub の Secrets の `STAFF_INITIAL_PASSWORD` を、仮のものから本物の長いものに変える。管理画面の各アカウントのパスワードも、ログインして変えてもらう
- [ ] (製作者)GitHub の Variable に `CREATE_DEMO_STAFF` = `false` を入れ、デモ用の受付スタッフ(`staff@greendome.example`)を作らないようにする。すでにあるデモ用のアカウントは、管理画面のスタッフの管理で止める
- [ ] (依頼主)受付スタッフのアカウントを使うなら、管理画面のスタッフの管理で、一人ずつ作る

## 4. データを本番用にする

- [ ] (製作者)デモで入れた試しのおうち・来場・予約を整理する。物理削除はしないので、本番用のデータベースを新しく作り直すか、デモ用の記録を「試し」として扱うかを依頼主と決める
- [ ] (依頼主)管理画面の設定を確かめる: 施設の名前、ポイントと無料券のルール、移行期間(未設定 = いつでも引き継げる)、天気の観測地点(三木)、予約の受け入れ数・料金(中型は仮)・預け・お迎えの時間・定休日・確認事項
- [ ] (依頼主)利用規約とプライバシーポリシーの本文を差し替える(いまは「準備中」の文)
- [ ] (依頼主)製作者の連絡先を設定に入れる(困ったときの画面に出る)

## 5. お店の準備

- [ ] (依頼主)受付の QR コードを、管理画面の設定から画像で保存して印刷し、受付に置く
- [ ] (依頼主)リッチメニューの画像を `docs/line/richmenu.jpg` に差し替える(6分割のテンプレート、docs/line/richmenu.md)
- [ ] (依頼主)切り替えの日を決め、管理画面の「切り替えの手順」に沿って進める。切り替えの日から旧カードにはポイントを付けない。LINE のショップカードは、引き継ぎがひととおり済んでから止める(止めるとお客さんのポイントが消え、元に戻せない)
- [ ] (依頼主)お知らせを LINE の一斉配信で送るか決める(無料は月200通まで。予約のお知らせと同じ枠を使う)

## 6. 実機での確認

- [ ] (依頼主・製作者)iPhone と Android の LINE で、docs/line-check.md の手順を通す: 登録、チェックイン、無料券のスライド、家族の招待、背景の写真、予約、旧カードの案内
- [ ] (依頼主)電波の弱いところで、機内モードにしてチェックインし、「送信を待っています」と出て、機内モードを解くと自動で送られることを確かめる
- [ ] (依頼主)予約を申し込み、管理画面で承認して、トークに「確定しました」が届くことを確かめる

- [ ] (依頼主・製作者)バックアップの合言葉 `BACKUP_PASSPHRASE` を決めて GitHub の Environment「Secret」に入れ、両方で控える(なくすと戻せない)
