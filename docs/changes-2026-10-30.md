# 2026-10-30 の依頼主の回答で決まったこと(旧カードの引き継ぎ)

`docs/requirements.md` の 16章・19.2・20章に反映した。この文書は決定の記録。

## 1. 上限を超えた分

- 旧カードから一度に引き継げるのは 30ポイントまで(設定 `migration_max_points`)。超えた分は引き継がない。
- お店が補うときは、ポイントの手動登録(A-03)で理由を書いて登録する。
- 上限は、カード1枚ごと(下の 3)。

## 2. 現行の LINE ショップカードの中身

- ゴールは 10ポイント、特典は「来場1回分が無料」。新しい会員証と同じなので、ポイントは1対1で引き継ぎ、使っていない特典1枚は無料券1枚にする(設定 `migration_max_tickets` の初期値 1枚、カード1枚ごと)。
- ポイントと無料券の有効期限は、まだ分からない(20章の未決事項のまま)。

## 3. 家族それぞれのカードも引き継ぐ(「1おうち1回」から「カード1枚ごとに1回」へ)

- 引き継ぐたびに、だれ(おうちの家族 = LINE アカウント)のカードかを選ぶ。初めの選択は、今日チェックインした家族(いなければ、家族が1人ならその人)。
- LINE のショップカードは LINE のアカウントに1枚なので、家族1人につき1回。紙のカードも家族1人につき1回。
- カードの番号が同じなら、ほかのおうち・同じおうちのほかの家族の分でも知らせる(これまでどおり)。
- 上限(30ポイント)と特典の上限(無料券1枚)は、カード1枚ごと。
- 同じ LINE のユーザーが抜けて別のおうちに入り直しても、同じカードは2回引き継げない。
- 統合でまとめても、ポイントは二重にならない。元に戻すのはカード1枚ずつ。
- 会員証の案内は家族ごとにする: 本人のカードをまだ1枚も引き継いでいなければ、ほかの家族が引き継いでいても出す。来場履歴の「前のカードからの引き継ぎ」には、おうちの家族全員の分を、だれのカードか(「あなたの」「パパさんの」)と一緒に出す。
- 管理画面(M-09)は「だれのカード」を選ぶ欄と、選んだおうちで引き継いだカード(だれの・どのカード・何ポイント)の一覧を出す。
- この決まりより前の記録(だれのカードか残っていないもの)は、「だれのカードか記録なし」として一覧に出し、ほかの引き継ぎは止めない。

## 4. 切り替えの日から旧カードにはポイントを付けない

- 切り替えの日(移行期間の初日)から、LINE のショップカードと紙のカードにはポイントを付けない(同じ来場のポイントが二重にたまるのを防ぐ)。ショップカードそのものは、移行期間が終わってから止める。
- 切り替えの手順(M-19)とお知らせの文に、はっきり書く。
