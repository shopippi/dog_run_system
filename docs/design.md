# デザインの指針

このシステムの画面の作り方。お客さん向け(apps/liff)と受付・管理画面(apps/admin)の両方に適用する。実装するときも、レビューするときも、この文書を基準にする。

## 1. 目指すもの

- 日本国内の大手 SaaS(freee・SmartHR・マネーフォワード)と同じ水準の、静かで密度のある業務画面。色ではなく、余白・文字の大きさ・線の濃さで整える。
- 犬の写真と名前が主役。装飾は主役を邪魔しない。
- 「何をすればよいか」が、説明を読まなくても分かる。主な操作は画面に1つ。
- 施設の名前は「グリーンドーム」(設定 `facility_name` から読む)。名前が「グリーン」でも、画面を緑にしない。

## 2. やってはいけないこと(「AI が作った画面」に見える要因)

- グラデーションの背景、カードの中のカード、要素ごとの大きな角丸(14px 以上)、全部が丸いピル形の部品
- パステル色の塗りつぶしの案内ボックスを、画面のあちこちに置く
- 破線の枠、絵文字、頭文字の丸いロゴ(「DR」など)、意味のない飾りのアイコン
- すべてを中央寄せにする。見出しをやたら太くする(700 を多用する)
- 色を何色も使う。アクセント色を無理に使う(主ボタンは墨色。色は「リンク・フォーカス・選択中」と「意味のある印(危険・注意)」にだけ使う)
- 1画面に目立つボタンを2つ以上置く
- 悲しい言葉・冷たい言葉(「登録解除」「削除」「亡くなった」「エラー」)を画面に出す。ワンちゃんの登録をやめるときは「おやすみ」と言う

色の使い分け: 主ボタンは ink。accent は「リンク・フォーカス・選択中の印」だけ。背景に色を広く塗らない。緑は使わない(info/warning/danger の意味色だけが残る)。

### 文字

- フォント: `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic Medium", "Segoe UI", Roboto, sans-serif`。Web フォントは読み込まない。
- 大きさ: 12 / 13 / 14 / 15 / 17 / 20 / 24。時計だけ 40。
- 本文は 15px(LIFF)・14px(管理画面)。行間 1.55。
- 見出しは 600。700 は使わない。見出しには `font-feature-settings: "palt"`。
- 数字は `font-variant-numeric: tabular-nums`。会員ID・犬ID・時刻は `ui-monospace, "SF Mono", Menlo, Consolas, monospace` の 13〜14px、letter-spacing .02em。
- 説明文は text-secondary、補足は text-tertiary の 13px。

### 間隔・角丸・影

- 4px を基準に 8 / 12 / 16 / 20 / 24 / 32。
- 角丸: 6(バッジ・小さな部品)、8(ボタン・入力欄・チップ)、12(パネル・カード)。それ以上は使わない。アバターだけ円。
- 影: パネルには付けない(1px の線だけ)。浮いている部品(ダイアログ・シート)だけ `0 8px 24px rgba(16,24,40,.12)`。
- フォーカス: `outline: 2px solid var(--focus); outline-offset: 2px`。薄い影だけのリングにしない。
- 押せない主ボタン: 色はそのままで `opacity: .45`(入力欄に見せない)。
- 文字と背景のコントラスト比は、すべて 4.5:1 以上(e2e/contrast.spec.ts が確かめる)。押せないボタンと placeholder は例外。
- 動き: 150ms ease-out。跳ねない。`prefers-reduced-motion` を尊重する(チェックイン完了の時計は動かす)。

## 5. お客さん向け(LIFF)の画面

- ヘッダー: 高さ 48、白、下に 1px の線。左に「グリーンドーム 会員証」の文字(15/600。施設名は設定から)。ロゴの丸は置かない。下の階層では左に「‹」のアイコンと戻り先の名前(ghost ボタン、44px)。
- ページの余白: 左右 20、上 20、下 32 + safe-area。
- 会員証(L-07): 角丸 12、縦横比 1.58:1(クレジットカードと同じ)の面に、**お客さんが選んだ背景**を敷く。背景は「自分の写真(おうちで共通。スマホで 1200px 以下に縮小して送る。`object-fit: cover`)」か「単色のプリセット 8 色(墨 #1F2328、紺 #1F3A5F、深緑 #1E4D3A、茶 #5A3E2B、ワイン #6B2737、灰 #6B7280、砂 #E9E2D3、白 #F6F6F4)」。初期値は墨。写真の上には必ず、下 60% に向かって濃くなる影(`linear-gradient(to top, rgba(0,0,0,.62) 0%, rgba(0,0,0,.28) 45%, rgba(0,0,0,0) 100%)`)を重ね、文字には `text-shadow: 0 1px 2px rgba(0,0,0,.45)` を付ける。明るい単色(砂・白)では影を重ねず、文字を text(墨)にし、text-shadow を外す。上段は左に呼び名 17/600(2行まで)、右に小さく施設名 12。中段は犬のアバター(32px、重ね -8px)。下段は左下に会員ID(mono、on-card-85)、右下にポイント数(24/600 tabular と「ポイント」12)。カードの右上に「背景を変える」の小さな ghost ボタン(アイコン `image`、on-card)。
- スタンプ(会員証の下のパネル「スタンプ」): 白いパネル(1px border、角丸 12)に、肉球のスタンプを 5×2 で並べる(1つ 36px)。たまった分は ink の肉球(SVG。押した跡らしく、1つずつ −6〜+6 度の傾きと 92〜100% の不透明度を index から決めて付ける。ランダムにしない)。まだの分は border-strong の 1.5px の輪郭だけ。10 個目は骨の形(たまったら ink の塗り)。10 個を超えた分は「11個目から」として次の列に続ける(最大 2 段)。新しく付いた 1 個は、開いたときに `transform: scale(1.4) → 1` を 250ms で 1 回だけ動かす(reduced-motion では動かさない)。パネルの右上に「3 / 10」(mono)。下に 15px で「あと 7 ポイントで無料券と交換できます」。10 以上たまっていれば主ボタン「無料券と交換する」。
- 無料券(会員証の下のパネル): 未使用の券を行で並べる(左にチケットのアイコン、「無料券」15/600、発行日 13 text-secondary、右に副ボタン「使用する」)。0 枚なら「使える無料券はありません」の一文。使用済みは「使った券」として折りたたみ。
- 会員証ページ全体の並び: 会員証 → 主ボタン「チェックイン」 → スタンプのパネル → 無料券のパネル → メニュー(ワンちゃん・家族・背景を変える)。
- 背景を変える(L-07b): 単色 8 色のチップ(40px の丸、選択中は ink の 2px の枠 + チェック)と「写真を選ぶ」の副ボタン、写真を使っているときは「写真をやめる」の ghost。その場でカードの見た目が変わる。保存は自動(変えたらすぐ API に送る)。
- チェックイン完了(L-06): 白いページ。上に小さく accent の点(ゆっくり明滅)と「チェックイン完了」「10月28日(水)」。その下に時計 40px tabular 600。時計の下に 3px の細いバーが左から右へ流れ続ける(スクリーンショットと見分けるため)。犬のアバター 72 と名前 20/600。「2頭 · DR-000001 · +1ポイント」を text-secondary の一行で。無料券を使った日は warning-50 の大きなブロックに「無料券を使用」(20/600)。下に数値ブロック(いまのポイント・使える無料券)。戻るのは ghost ボタン。
- 登録の流れ(L-01〜L-04): 上に 3 本の細いバーで進み具合。見出し 20/600、説明 15。利用規約は行(タイトル + 右に「›」)で、開くと本文。写真は「写真を選ぶ」の副ボタン(破線にしない)。「この子を削除」は右上の ghost(danger の文字)。
- 犬の一覧(L-09): 行(アバター 48、名前、犬種・サイズ、右に「›」)。「ワンちゃんを追加」は副ボタン。「おやすみ中のワンちゃん」は一番下に小さい見出しで、行は text-tertiary。
- 犬の変更(L-10): 見出し「○○の変更」。写真・名前・性別・生まれた年月・体重・相性・予防注射の年。保存は主ボタン。一番下に、説明文なしで 13px の ghost ボタン「この子の登録をおやすみする」(text-tertiary。danger の色を付けない)。押したときの確認は「○○の登録をおやすみします。来場の記録はそのまま残り、いつでも戻せます。」ボタンは「おやすみする」「やめる」。
- 家族を招待(L-11): QR は白い枠(1px border、padding 16)の中。主ボタン「LINEで招待を送る」、副ボタン「QRコードを表示」。

## 6. 受付・管理画面

- レイアウト: 幅 960px 以上では左にサイドバー(幅 232、surface、右に 1px の線)。上にシステム名「グリーンドーム 受付・管理」(施設名は設定から)、その下にメニュー(高さ 40、アイコン 18 + 文字 14、選択中は surface-sunk の背景 + text、それ以外は text-secondary)。一番下にログイン中の名前と役割、ログアウト(ghost)。960px 未満では上にバー(高さ 52)とその下に横スクロールのメニュー。
- 本文の下地は canvas。本文の最大幅 1100、padding 24。
- ページの頭: タイトル 20/600、使い方 13px text-secondary(1〜3行)。右に操作があれば置く。
- 製作者(見るだけ)の表示: 本文の上に info の inline alert を1つ。帯にしない。
- 今日の来場(M-02): 数値ブロック 4 つを 1 つのパネルに。その下に「会員以外のお客さん」の行(文字・ステッパー・副ボタンを 1 行に、パネルの中)。来場の一覧は、時刻(mono)| アバター | 名前 15/600 と「呼び名 · DR-000001 · パパさん」13 text-secondary | バッジ | 右端に ghost「取り消す」。取り消し済みは文字を text-tertiary にしてバッジを付ける。新しい行は surface-sunk から白へ 2 秒で戻る。
- 取り消しの確認: ダイアログ。タイトル「チェックインを取り消す」、元に戻る内容の箇条書き、理由のチップ、右下に「やめる」「取り消す(danger 塗り)」。
- おうちを探す(M-04): 検索欄は高さ 48、左に虫めがねのアイコン。探し方はセグメント。結果は行(アバターの重なり、呼び名、会員ID、最後の来場、右に「›」)。写真で探すは 120px の正方形の写真のグリッド。選んだおうちはパネル(1px border)にして、犬の写真 80、名前、家族、操作を置く。
- 代理チェックイン(M-03): おうちを探す画面と同じ。選んだおうちのパネルの中に、日付・犬の選択行・無料券のチェック・主ボタン。
- ログイン(M-01): canvas の中央に幅 400 のパネル。システム名、2 つの入力欄、主ボタン。

## 7. アイコン

線のアイコンを最小限だけ、インラインの SVG(stroke 1.75、24 グリッド)で持つ: chevron-left、chevron-right、search、plus、minus、calendar(今日の来場)、users(おうち)、clipboard(代理)、log-out、image(背景を変える)、ticket(無料券)。絵文字と塗りのアイコンは使わない。例外は会員証のスタンプ(肉球と骨の塗りの SVG)だけ。

## 8. アクセシビリティと端末

- 押す部品はすべて 44px 以上。管理画面だけは、マウスの端末では 40 以上でよい(タッチの端末では 44)。
- 入力欄の文字は 16px 以上。
- フォーカスリングを消さない。
- ダークモードに対応する(トークンで切り替える)。
- iPhone SE(375px)から PC(1280px)まで、横にはみ出さない。
