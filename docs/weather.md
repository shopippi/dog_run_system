# 天気の取得(B-01)

毎朝 5:10(日本時間)に、前日の天気・最高気温・最低気温・降水量を気象庁のデータから取り、`daily_weather` に入れる。ダッシュボードの「天気の影響」「気温の影響」に使う。

## 取得元

気象庁の「過去の気象データ検索」はブラウザ向けの HTML しかなく、決まった形の API がない。そこで、気象庁のサイトの「アメダス」の画面が使っている、公開の JSON を使う。

```
https://www.jma.go.jp/bosai/amedas/data/point/<地点番号>/<YYYYMMDD>_<HH>.json
```

- `<地点番号>` はアメダスの観測地点の5桁の番号。設定(settings)の `weather_station.code` に入れる。初期値は東京(`44132`)。
  ほかの地点の番号は `https://www.jma.go.jp/bosai/amedas/const/amedastable.json` で調べられる(キーが地点番号、`kjName` が地点名)。ドッグランの所在地が決まったら(要件定義書 20章の未決事項)、近い地点に変える。
- `<HH>` は `00`・`03`・…・`21`。1つのファイルに3時間分の、10分ごとの観測値が入る。
- 中身は `{ "20261027001000": { "temp": [12.3, 0], "precipitation10m": [0.0, 0], "sun10m": [10, 0], … }, … }`。
  値は `[値, 品質の印]` の組で、値が `null` のこともある。
- 公開されているのは、およそ過去10日分まで。それより前の日は取れない(取り直しは過去7日までにしている)。

## 項目の対応

気象庁の日の区切り(0時10分〜24時00分)に合わせ、その日の `00`〜`21` のファイルと、翌日の `00` のファイルの 0:00 の値を使う。

| daily_weather の列 | 作り方 |
| --- | --- |
| `temp_max` | 10分ごとの気温(`temp`)の最大 |
| `temp_min` | 10分ごとの気温(`temp`)の最小 |
| `precipitation` | 10分間降水量(`precipitation10m`、mm)の合計。小数1桁 |
| `sunshine_hours` | 10分間日照時間(`sun10m`、分)の合計 ÷ 60。小数1桁 |
| `weather` | 下の規則で決める |
| `station` | 設定の `weather_station.name`(例: 東京) |
| `source` | 「気象庁」(出典の表示に使う) |

- 気温の最高・最低は10分ごとの値から出すので、気象庁が発表する日最高・日最低気温(瞬間の値)とは 0.1〜0.5 度ほどずれることがある。
- 10分ごとの値が1日(144回)のうち132回(2時間分の欠け)より少ない日は「まだそろっていない」として入れず、翌朝に取り直す。

## 天気の決め方

アメダスには「晴れ・曇り」の観測がないため、降水量と日照時間から決める(`packages/shared/src/analytics.ts` の `classifyWeather`)。

| 天気 | 条件 |
| --- | --- |
| 雨 | 1日の降水量が 1.0mm 以上(気象庁の「雨日」と同じ基準) |
| 晴れ | 雨でなく、日照時間が 4時間以上(昼の長さのおよそ4割) |
| 曇り | それ以外 |

降水量が分からない日、雨でなく日照時間も分からない日(日照を測っていない地点など)は、天気を空(`null`)にして、天気の分析に入れない。

## 取り直し

- 前日の分が取れなかったとき(気象庁のサイトの不調など)は、`system_jobs` に「失敗」を残し、翌朝に取り直す。
- 毎朝、過去7日分のうち `daily_weather` に無い日を、新しい日から順に取りに行く。
- Workers の無料プランは、1回の実行で外部へのリクエストが50件まで。1日分で9件(隣の日と共有するファイルは1回だけ)使うので、1回に取るのは5日分まで。残りは次の朝に取る。

## 出典の表示

気象庁のデータは、出典を書けば商用でも使える(気象庁ホームページの利用規約)。ダッシュボードの天気のグラフの下に「天気: 気象庁のアメダス(東京)の観測値をもとに作成」と表示する。

## 取得元を差し替えるとき

`apps/api/src/services/weather.ts` の `WeatherSource`(`fetchDay(station, date)` で1日分を返す)を実装し、`runWeatherJob` に渡す。気象庁の JSON の形が変わったときは `JmaAmedasSource` を直し、`apps/api/test/b01-weather.test.ts` の偽の応答も合わせる。
