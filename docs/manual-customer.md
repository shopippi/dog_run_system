# ドッグラン会員証のご案内(お客さま向け)

LINE の中で使える、ドッグランの会員証(ポイントカード)のご案内です。店頭の案内や、LINE のメニューの説明にお使いください。写真は見本の画面で、名前や数字は架空のものです。

- 受付の QR コードを読み取るだけで、チェックインできます。
- 1日1ポイント。10ポイントで、無料券が1枚(来場1回分)もらえます。
- ご家族の LINE と、ポイントをいっしょにためられます。

## 1. 登録する(はじめての方)

1. ドッグランの LINE 公式アカウントを友だちに追加します。
2. 受付の QR コードを、LINE のカメラで読み取ります。「はじめての方へ」の画面が開きます。
3. 利用規約とプライバシーポリシーを読み、「同意します」に印を付けて「同意して次へ」を押します。
4. ワンちゃんの写真・名前・犬種・サイズを入れて「次へ」を押します。2頭以上いるときは、続けて追加できます。
5. かんたんなアンケートに答えて「登録する」を押します。
6. 「登録が完了しました」と会員ID(DR-000123 のような番号)が出たら完了です。

| 同意 | ワンちゃんの登録 | アンケート | 登録の完了 |
| --- | --- | --- | --- |
| ![はじめての方へ](images/manual/customer-consent.png) | ![ワンちゃんの登録](images/manual/customer-dogs.png) | ![アンケート](images/manual/customer-survey.png) | ![登録の完了](images/manual/customer-done.png) |

- 写真は、受付でお客さまを確認するのに使います。あとからでも登録できます。
- 会員IDは、ご家族で共通です。受付でたずねられたときは、この番号をお伝えください。

## 2. チェックインする

1. 受付の QR コードを、LINE のカメラで読み取ります(会員証の「チェックイン(受付のQRを読む)」からも読み取れます)。
2. 今日来たワンちゃんに印を付けます。
3. 無料券を使うときは、「無料券を使う」に印を付けます。
4. 「チェックインする」を押します。
5. 「チェックイン完了」の画面を、受付で見せてください。

| ワンちゃんを選ぶ | チェックイン完了 |
| --- | --- |
| ![チェックイン](images/manual/customer-checkin.png) | ![チェックイン完了](images/manual/customer-checkin-done.png) |

- ポイントは、おうちごとに1日1ポイントです。ワンちゃんが何頭いても、ご家族の誰がチェックインしても、1日1ポイントです。
- ご家族がその日にもうチェックインしているときは、一緒に来たワンちゃんを追加するだけになります(ポイントは増えません)。
- 無料券を使った日も、1ポイントたまります。もらった無料券は、次の来場から使えます。
- スマホを忘れた日も、受付でチェックインできます。

## 3. 会員証を見る

LINE のトーク画面の下のメニューから、会員証を開けます。

![会員証](images/manual/customer-card.png)

- ポイントと、次の無料券まであと何ポイントかが分かります。
- 「ワンちゃん」から、写真・名前・性別・生まれた年月を変えたり、ワンちゃんを追加したりできます(犬種とサイズは受付で変えます)。
- 「来場履歴」で、これまでの来場が見られます。

## 4. ご家族を招待する

ご家族が同じ会員証を使うと、誰がチェックインしても同じ会員証にポイントがたまります。

1. 会員証の「家族を招待」を押します。
2. 「LINEで招待を送る」を押し、送りたいご家族を選んで送ります。ご家族がそばにいるときは「招待のQRコードを表示する」を押し、ご家族の LINE のカメラで読み取ってもらいます。
3. ご家族が招待を開き、年代・性別を選んで、「同意します」に印を付けて「参加する」を押します。
4. 「参加しました」と出たら完了です。ご家族の会員証にも、同じ会員ID・ポイント・ワンちゃんが出ます。

| 招待を送る | 招待を受けたご家族の画面 |
| --- | --- |
| ![家族を招待](images/manual/customer-family.png) | ![招待からの参加](images/manual/customer-join.png) |

- 招待は24時間有効で、1回だけ使えます。ご家族1人につき1つ送ってください。
- ご家族がすでに別の会員証でポイントをためているときは、「おうちをまとめる申請」になります。受付で確認してから、1つにまとめます(ポイントは合計されます)。
- 受付で、家族を追加する QR コードを出してもらうこともできます。

## 5. 前のカードのポイントを引き継ぐ

LINE のショップカードと、紙のスタンプカードのポイントを引き継げます。

![旧カードの引き継ぎ](images/manual/customer-migration.png)

1. 会員証の「旧カードの引き継ぎ」を押します。
2. 「引き継ぐカード」(LINE のショップカード・紙のスタンプカード)を選びます。
3. 「写真を撮る・選ぶ」を押し、ポイントの数が読めるようにカードの写真を撮ります。LINE のショップカードは、画面を保存した写真でも大丈夫です。
4. 分かれば「だいたいのポイント数」を入れて、「申請する」を押します。
5. 受付で写真を確認すると、会員証のポイントに加わります。

- カードの種類ごとに1回ずつ申請できます。
- 申請できる期間は、画面に表示されています。
- 受付でカードを見せて、その場で引き継いでもらうこともできます。

## 困ったときは

会員証が開かない、ポイントが合わない、ご家族のつなぎ方が分からないなど、困ったときは受付のスタッフにお知らせください。会員証の下の「使い方・よくある質問」にも説明があります。
